# 结果文件字典

先看 [实际分析报告](../results/分析报告.md)，需要理解某个字段时再查这里。CSV 使用 UTF-8 并带 BOM；分析脚本以完整精度导出统计量，报告展示的少量小数不替代原始统计表。

## 图在哪里，每张说明什么

## 输入与环境

| 文件 | 字段/内容 | 说明 |
| --- | --- | --- |
| `tables/input_manifest.csv` | file, url, bytes, sha256 | 18 个官方输入的链接、大小与指纹 |
| `tables/package_versions.csv` | package, version | 主要分析包的实际版本；完整依赖见 renv.lock |
| `config/samples.tsv` | sample_id, gsm, group, file_label, timepoint | 根目录 config 中的样本对应表 |
| `config/input_checksums.tsv` | file, sha256 | 发布基准输入指纹，不应为通过校验随意改写 |
| `logs/sessionInfo.txt` | R、系统、locale、加载包 | 实际运行会话信息 |
| `logs/analysis.log` | 各步骤输出 | 全流程执行记录 |
| `logs/console.log` | 标准输出、消息、警告 | 本次命令行额外捕获；普通 source 不自动更新它 |
| `logs/parameters.R` | cfg 列表 | 实际参数快照 |
| `logs/verification.txt` | PASS 摘要 | 执行 verify_results.R 后生成 |
| `run_summary.json` | 细胞数、簇数、差异数等 | 机器可读摘要 |

上表除 `config` 和 `renv.lock` 外，其余路径相对 `results/`。

## 质控和细胞信息

**qc_summary.csv**：一行一份样本。`input_cells` 是下载矩阵列数，`qc_pass_cells` 是通过阈值的数量，`analyzed_cells` 是抽样后进入分析的数量，`retained_percent` 是质控合格比例，区别于抽样比例。

**qc_all_cells.csv**：一行一个下载条形码。`cell` 已加样本前缀；`nCount_RNA` 为总 UMI，`nFeature_RNA` 为检出基因数，`percent.mt` 为线粒体 UMI 百分比。`pass_qc` 表示是否合格，`selected` 表示是否选入分析。合格细胞可能未被抽中。

**analyzed_cell_metadata.csv**：一行一个选中细胞，包含 `sample_id/group`、质控、`seurat_clusters/cell_type` 与 `UMAP_1/UMAP_2`。`orig.ident` 是创建 Seurat 对象时的样本来源。`RNA_snn_res.0.4` 是该分辨率聚类标签，修改参数后列名可能变。UMAP 坐标不是组织空间位置。

**celltype_composition.csv**：一行一个“样本 × 暂定细胞类型”组合。`n_cells` 为选中细胞数，`proportion` 为样本内比例，每样本相加为 1。零值不能证明组织中绝对不存在该细胞。

## 注释证据

**annotation_marker_panel.csv**：候选 `cell_type`、标记 `gene`、矩阵中是否存在 `present`。面板列出候选谱系，不保证全部捕获。

**cluster_annotation_scores.csv**：每行一个簇，各列为候选组合的平均 Z 分数；不是概率或 FDR。

**cluster_annotation.csv**：

| 字段 | 含义 |
| --- | --- |
| cluster | 无监督簇编号，换参数后未必对应 |
| n_cells | 该簇细胞数 |
| candidate / second_candidate | 自动第一/第二候选 |
| top_score | 最高标记组合得分 |
| score_gap | 第一与第二得分差 |
| cell_type | 最终暂定标签，可能人工复核修改 |
| annotation_basis | 自动规则或人工复核理由 |

本次 cluster 4 使用 `Mural_cells`（血管壁细胞，周细胞/平滑肌粗合并）；cluster 13 使用 `Uncertain`（混合小胶质/内皮信号）。不确定簇保留在图和组成中，排除在小胶质伪 bulk 外。

**cluster_marker_evidence.csv**：每行一个“簇 × 标记基因”。`mean_log_normalized` 为 log 标准化表达均值，`pct_detected` 为检出百分比。它与 DotPlot 的缩放颜色不在同一尺度，便于审阅具体数值。

**cluster_markers_exploratory.csv / cluster_top10_markers.csv**：簇对其余细胞的探索性 Wilcoxon。每类最多 150 个细胞参与检验。`avg_log2FC` 为该簇相对表达效应，`pct.1/pct.2` 为两侧检出比例，`p_val/p_val_adj` 为细胞层面统计量。top10 按正向效应大小选择；它不是动物层面的疾病检验，也不是独立验证。

## 小胶质细胞伪 bulk

**microglia_pseudobulk_cell_counts.csv**：一行一个样本，`n_cells` 是纳入的已注释小胶质细胞数。应含全部 6 份样本，每份至少 20 个细胞。

**microglia_pseudobulk_raw_counts.csv**：行是基因，六列是六份样本内小胶质细胞原始 UMI 之和。非负整数，不能用标准化值或均值替代，仍包含未达到后续表达过滤的基因。

**microglia_library_sizes.csv**：`lib.size` 为通过基因表达过滤后的计数文库总量，`norm.factors` 为 TMM 因子，二者决定有效文库大小；不是细胞总数。

**microglia_logCPM.csv**：通过表达过滤后的六样本 TMM log2 CPM，`prior.count = 2`。用于热图、样本表达图与样本 PCA；正式差异检验仍基于计数模型。

**microglia_pseudobulk_DE_all.csv**：全量样本层面检验表，字段如下：

| 字段 | 含义 |
| --- | --- |
| gene | 基因名 |
| logFC | log2(MCAO/Sham) 的模型效应 |
| logCPM | 平均表达概括 |
| F | QL F 检验统计量 |
| PValue | 未校正 P 值 |
| FDR | 多重检验调整值 |
| direction | 按 FDR < 0.05 且 abs(logFC) ≥ 1 分类 |

`direction` 为 `Higher_in_MCAO`、`Lower_in_MCAO` 或 `Below_threshold`。设计是 `~ group`，参考 Sham。

**microglia_pseudobulk_DE_significant.csv**：按联合门槛筛选的子集。未列出的基因可能未达门槛或根本未被检验，不能据此说它完全不表达或绝对无变化。
